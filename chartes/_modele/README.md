# Charte graphique

Déposer ici :
- `template.pptx` — modèle de diapositives (masques, mises en page)
- `template.docx` — modèle pour cahier formateur, énoncés, évaluations
- `logo.*`
- `charte.md` — couleurs (hex), polices, règles d'usage

- `charte-technique.json` — généré puis validé via la skill `/preparation-charte` (correspondance mises en page/styles, police de code, limites de densité)

Les agents n'inventent aucune couleur ni police : tout vient d'ici.
