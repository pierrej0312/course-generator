# Exemple de test des scripts

Fichiers utilisés pour tester `genere_pptx.py` et `genere_docx.py` avec une charte **factice**
(templates vierges par défaut de python-pptx / python-docx, élargis en 16:9 sans adapter les mises en page :
d'où le contenu décalé à gauche). Ce n'est pas une charte réelle.

- `slides.md` / `cahier.md` : exemples du format markdown attendu
- `apercu-slides.png` / `apercu-cahier.png` : planches produites par `apercu.sh`
  (la diapo « Trop chargée » et le `[À VÉRIFIER]` déclenchent volontairement des alertes)
