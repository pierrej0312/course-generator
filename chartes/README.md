# Chartes graphiques

Une charte par organisation, client ou formateur : `chartes/<nom>/`.
La charte utilisée pour un cours est indiquée dans son brief ; à défaut, celle par défaut du profil formateur.

Contenu d'une charte (voir `_modele/README.md`) : `charte.md`, `template.pptx`, `template.docx`, logo.
Les agents n'inventent jamais de couleur ni de police : si la charte est absente ou incomplète, ils s'arrêtent et le signalent.
