# Installer le Course Generator dans ChatGPT

1. Dans ChatGPT, créez un projet privé nommé **Course Generator**.
2. Dans **Paramètres du projet**, collez tout le texte de `Instructions.txt` dans les instructions.
3. Dans **Sources**, ajoutez `Methodologie.txt`, `Modeles.txt` et `Exports.txt`. Ces trois fichiers suffisent pour démarrer.
4. Ouvrez un chat dans le projet et écrivez **Nouveau cours**. Préparez un exemple de votre façon d'expliquer et, pour les exports aux couleurs de votre organisation, ses modèles PowerPoint et Word.

Pour le premier essai, écrivez par exemple « Nouveau cours. Formation de 3 h 30 en présentiel sur les tableaux croisés dynamiques pour des débutants qui connaissent les formules de base. » ChatGPT devrait relever ce qui manque, préparer un brief et attendre votre validation.

Pour un autre cours, ouvrez un autre chat dans le projet. Gardez les documents propres à un cours dans son chat et demandez **Prépare le dossier de reprise** avant de changer de chat. Téléchargez le dossier et joignez-le ou joignez ses fichiers utiles si vous reprenez ailleurs.

Vous pouvez distribuer ce dossier à chaque formateur pour qu'il configure son propre projet. Dans un projet partagé, les membres peuvent consulter ses chats et fichiers. Réservez les sources communes aux modèles et références partageables.

## Ce qui se passe dans ChatGPT

- La conception, les simulations et les validations se font dans la conversation. Pour les affirmations techniques, utilisez la recherche web ou joignez la documentation officielle.
- Les exports téléchargeables dépendent des outils de génération de fichiers disponibles dans le chat. Les modèles Office et la charte technique sont à joindre si vous souhaitez reproduire le rendu de votre organisation. À défaut d'outil compatible, les sources Markdown restent utilisables.
- Pour Google Forms, ChatGPT peut préparer les questionnaires et produire le script. La création du formulaire se fait dans votre navigateur avec votre compte Google. L'évaluation et le feedback restent utilisables sur papier.
- Pour Drive, Agenda et Sheets, utilisez un connecteur s'il offre l'action voulue. Sinon, déposez les fichiers dans Drive, importez le calendrier `.ics` et joignez les réponses exportées en CSV pour les analyser.
