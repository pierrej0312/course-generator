# Bibliothèque

Sujets mis de côté parce qu'ils sortaient du périmètre d'un cours, mais réutilisables ailleurs.

- `sujets/` — un fichier par sujet (template : `templates/sujet-bibliotheque.md`)
- `index.md` — liste des sujets, tags et cours qui y font référence
- `sources-officielles.md` — domaines de documentation officielle par technologie
