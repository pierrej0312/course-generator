# Profils formateurs

Chaque personne qui utilise ce dépôt a son propre profil : ton, vocabulaire, personnalité, façon d'expliquer.
Les agents rédacteurs écrivent **dans la voix du formateur indiqué dans le brief du cours**, jamais dans une voix générique ou celle d'un autre formateur.

## Créer son profil
Lancer la skill `/profil-formateur`. Elle :
1. copie `_modele/` vers `formateurs/<identifiant>/` ;
2. pose des questions sur ta façon d'enseigner ;
3. analyse tes anciens supports déposés dans `formateurs/<identifiant>/exemples/` ;
4. te fait valider chaque élément avant de l'enregistrer.

## Contenu d'un profil
| Fichier | Contenu |
|---|---|
| `profil.md` | Identité, domaines, personnalité pédagogique, charte par défaut |
| `voix.md` | Ton, registre, façon d'expliquer, extraits réels |
| `lexique.md` | Termes préférés, termes à éviter |
| `exemples/` | Anciens supports servant de référence |

`_modele/` est le squelette vierge : ne pas le remplir.
